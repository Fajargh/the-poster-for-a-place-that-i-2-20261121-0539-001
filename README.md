A program that draws a travel poster for VELMARA — The Lagoon of Glass Tides, a place that does not exist. Three glass lighthouses rise from a rocky islet in a violet lagoon at golden hour, their lamps lit, lanterns drifting on the water, and the tide — famously — never leaves. Everything is drawn in code with a pure-Python software renderer (standard library only, no network, no external files), so the poster is fully deterministic.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024×1024, under the 1 MiB cap) to `$MAKEFUN_OUTPUT_DIR` (or `/output`).
